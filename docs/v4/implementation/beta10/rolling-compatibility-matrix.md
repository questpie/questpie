# BETA-10 rolling compatibility matrix

Compatibility is a decision per artifact family, not one `old/new` Boolean.

| Family             | Compatible rolling case in beta.1                                                                                 | Refusal or retirement boundary                                                                                                             | Evidence                                                                                                                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## Exact claim

The v4 participant is a distinct, correctly re-signed Runtime Build whose only
changed compatibility dimension is `internalProtocol`. It is not represented as
an arbitrary historical server binary. This is sufficient for the v4-to-v5
rolling edge introduced by BETA-09; another compiler/runtime change must add a
row and evidence for every compatibility dimension it changes.
