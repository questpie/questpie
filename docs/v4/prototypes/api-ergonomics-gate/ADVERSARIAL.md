the proof design; it is not acceptance evidence. The proof repairs its concrete
findings as follows:

  claiming the old bracket-key examples already meant nested access; ADR and

  failures and are classified as contract-incompatible augmentation.

  `prototype.*`, and `*.toString.*` remain safe in frozen null-prototype trees.

  introduces a generated bootstrap dependency.
