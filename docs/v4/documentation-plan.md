# Public documentation routing

The early documentation-first plan is superseded by
[the tracer-led delivery flow](DELIVERY-FLOW.md) and the repo skill's
[public-documentation branch](../../.agents/skills/questpie-v4/references/public-documentation.md).

Public pages live in `apps/docs/content/docs/v4/`. They project Accepted ADRs
and identify actual release availability. Executed package examples and public
skills must agree with those pages. The current release scope is
[the beta.2 inventory](beta2-release-scope.md).

This path remains for historical projection references. It is not an active
backlog, a second source of product authority, or a reason to restart completed
documentation slices.
