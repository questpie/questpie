# Triage labels

| Canonical role    | Repository label  | Meaning                             |
| ----------------- | ----------------- | ----------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer must evaluate the issue  |
| `needs-info`      | `needs-info`      | Waiting for more information        |
| `ready-for-agent` | `ready-for-agent` | Fully specified for autonomous work |
| `ready-for-human` | `ready-for-human` | Requires a human decision or action |
| `wontfix`         | `wontfix`         | Intentionally not planned           |

Skills must use the repository label from this table.
