# QUESTPIE agent skills

The canonical sources are `skills/questpie/` and `skills/questpie-admin/` in
this repository. Their `SKILL.md` and `references/*.md` files are maintained by
hand; `AGENTS.md` is generated by `bun run scripts/build-skill-docs.ts` and must
never be edited directly.

Repository release tags snapshot the skill content together with the framework.
Project installs use the official `skills` CLI and record the resolved source
and content hash in `skills-lock.json`. That lock entry, not a developer's
pre-existing global skill directory, is the project-local provenance record.

Install or repair both skills from the canonical repository:

```sh
bunx skills@1.5.17 add questpie/questpie \
  --skill questpie questpie-admin --yes --copy
```

Inspect the project-local install:

```sh
bunx skills@1.5.17 list --project --json
```

Refresh it from the recorded source:

```sh
bunx skills@1.5.17 update --project --yes
```

Maintainers can verify a disposable install against the canonical inventories
and file hashes with `bun run verify:skills-install`.
