The Hono adapter connects QUESTPIE to the [Hono](https://hono.dev) web framework.

## Install

```bash
bun add @questpie/hono hono
```

## Setup

```ts title="src/index.ts"
import { Hono } from "hono";
import { questpieHono } from "@questpie/hono/server";
import { app } from "#questpie";

const server = new Hono();

server.route("/api", questpieHono(app));

export default server;
```

## Bun & SSE Keepalive

When serving with Bun, prefer the object export so you control `idleTimeout`. Bun's default is 10s — QUESTPIE's realtime SSE stream pings every 8s by default, which survives it, but explicit headroom avoids surprises:

```ts title="src/index.ts"
export default {
	port: 3000,
	idleTimeout: 30, // seconds — keeps SSE realtime streams alive
	fetch: server.fetch,
};
```

See [Realtime (Production)](/docs/production/realtime) for the full timeout matrix.

## With OpenAPI

OpenAPI is registered as a module rather than wrapping the handler. Add `openApiModule` to your `modules.ts`:

```ts title="modules.ts"
import { adminModule } from "@questpie/admin/modules/admin";
import { openApiModule } from "@questpie/openapi/modules/openapi";

export default [adminModule, openApiModule] as const;
```

The fetch handler stays the same — no wrapping needed:

```ts title="src/index.ts"
server.route("/api", questpieHono(app));

// OpenAPI spec at /api/openapi.json
// Scalar UI at /api/docs
```
