title: Use the QUESTPIE v4 API surface
description: Import structural builders, generated factories, clients, and optional runtime capabilities from their exact owners.

QUESTPIE v4 keeps one implementation kernel where semantics agree and exposes
only the capabilities valid for each job. Public names tell you which contract
owns the value.

## Build values once

Use `codec.*` for Operation input and output, Context input, durable payloads,
and Channel payloads:

```ts
import { codec, defineCollection, field } from "questpie";

const messageId = codec.uuid();

export const messages = defineCollection({
	name: "messages",
	fields: {
		id: field.uuid({ default: "randomUuid" }),
		body: field.text(),
	},
});
```

`codec.uuid()` and `field.uuid()` share scalar identity and validation. A Field
adds database-only behavior such as nullability, defaults, and column mapping.
`value.*` retains the compatible embedded-JSONB vocabulary. Operation does not
define a second `operation.uuid()` grammar.

## Import executable factories from the current contract

```ts
import { codec } from "questpie";
import { defineMutation, defineQuery } from "#questpie/app";

export const messageById = defineQuery({
	name: "messages.byId",
	input: codec.object({ id: codec.uuid() }),
	handler: ({ input, ctx }) => ctx.data.messages.get({ key: input }),
});

export const renameMessage = defineMutation({
	name: "messages.rename",
	input: codec.object({ id: codec.uuid(), body: codec.text() }),
	handler: ({ input, ctx }) =>
		ctx.data.messages.update({
			key: { id: input.id },
			patch: { body: input.body },
		}),
});
```

`#questpie/app` also exports `defineAction`, `defineRoute`, `defineReaction`,
`defineJob`, and `defineWorkflow`. Each factory has its own exact context; there
is no universal Definition builder. Packages import the same names from their
generated `#questpie/package` contract and cannot see host-only Resources.

## Keep Route and Fetch distinct

A Route owns raw HTTP behavior. It receives Request, parameters, ingress facts,
Route-safe Services, and `ctx.execution`. It receives no data facade or
transaction. The generated Runtime mounts Routes into `app.fetch`; there is no
`defineFetch`.

## Watch Queries; define Channels

A supported generated Query method gains `.watch` and returns complete freshly
authorized results. A Channel is a distinct Resource created with
`defineChannel`; it owns event codecs, subject identity, publish/subscribe
Policy, order, replay, and limits. Neither bypasses Policy.

## Configure capabilities, not providers

Optional runtime acceleration uses four distinct `questpie.json` keys:

```json
{
	"runtime": {
		"cache": { "service": "service:cache.redis" },
		"wakeBroker": { "service": "service:wake.redis" },
		"channelCarrier": { "service": "service:channels.pusher" },
		"byteStore": { "service": "service:bytes.s3" }
	}
}
```

Each value is an exact Service identity implementing that capability, not a
provider registry. Losing cache, broker, or carrier cannot lose authority or
durable progress; PostgreSQL remains the source of truth. Byte storage receives
no Principal, Policy, Collection, transaction, or raw database capability.

OpenAPI, MCP, and skills have no authoring import. Select them under
`questpie.json` `projections`, emit them with `questpie build`, and inspect them
with `questpie explain projection <openapi|mcp|skills>`.
