Use these entry points for application code. Generated names are specific to
your compiled application; run `questpie build` before checking them.

| Import                   | Values                                                                                                                                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `questpie`               | `defineCollection`, `defineCollectionAugmentation`, `defineCollectionOperations`, `defineSeed`, `defineContext`, `definePolicy`, `defineService`, `defineCredentialResolver`                                   |
| `questpie`               | `field`, `value`, `shape`, `codec`, `constraint`, `index`, `relation`, `relationRef`, `collection`, `seed`, `context`, `principal`, `policy`, `expr`, `query`, `dataQuery`, `operation`, `mutation`, `durable` |
| `#questpie/app`          | `defineQuery`, `defineMutation`, `defineAction`, `defineRoute`, `defineJob`, `defineReaction`, `createApp`, and exact generated application types                                                              |
| `#questpie/client`       | `createClient` and the exact generated network client                                                                                                                                                          |
| `#questpie/package`      | Generated executable factories for a reusable composition Package                                                                                                                                              |
| `questpie/react-query`   | `createQueryAdapter`                                                                                                                                                                                           |
| `questpie-opentelemetry` | `createOpenTelemetry`                                                                                                                                                                                          |

`questpie` also exports the TypeScript helpers `DiscriminatedValue`,
`DiscriminatedReference`, and `matchDiscriminated`. They model ordinary unions;
they create no relation, foreign key, codec, Policy traversal, or live dependency.

## codec

Codecs are runtime contracts for Operation input/output, Context input, and
durable payloads. They validate values and supply generated types and network
encoding. TypeScript interfaces disappear at runtime and cannot replace them.

| Builder                         | Purpose                                                     |
| ------------------------------- | ----------------------------------------------------------- |
| `codec.uuid()`                  | UUID string.                                                |
| `codec.text(options?)`          | Text with optional bounds.                                  |
| `codec.boolean()`               | Boolean.                                                    |
| `codec.integer(options?)`       | Integer with optional bounds.                               |
| `codec.timestamp()`             | Timestamp decoded as a Date.                                |
| `codec.object(members)`         | Closed object; unknown keys are rejected.                   |
| `codec.array(item)`             | Array; use a bounded list where the transport requires one. |
| `codec.list(item, { maximum })` | Bounded list.                                               |
| `codec.nullable(inner)`         | Explicit null or an inner value.                            |
| `codec.optional(inner)`         | Missing member or an inner value.                           |
| `codec.cursor()`                | Opaque framework cursor.                                    |

Bigint, numeric, date, and JSON contracts are available through Field-derived
input codecs; `codec` has no public factory for those kinds.

Use `field.*` for database fields and `value.*` for embedded JSONB members.
They share scalar rules but add different storage capabilities. Field-derived
`createInput` and `updateInput` retain constraints, bounds, nullability, and
write provenance.

A validation library can validate UI state or provider responses in application
code. Its arbitrary JavaScript refinements cannot replace a serializable
QUESTPIE boundary Codec. Keep boundary validation and domain invariants explicit.

See [Collections](/docs/v4/collections-reference),
[Operations](/docs/v4/executable-definitions), and
[the generated client](/docs/v4/client-reference).

## Discriminated application values

`DiscriminatedValue<{ ticket: { id: string }; note: { text: string } }>` produces
`{ kind: "ticket"; id: string } | { kind: "note"; text: string }` with readonly
members. `DiscriminatedReference<{ ticket: string; comment: string }>` produces
the corresponding `{ kind; id }` union for references.

`matchDiscriminated(value, cases)` requires exactly one callback for each
literal `kind`. Each callback receives its narrowed variant; the return type is
the union of callback results. Missing or unknown kinds fail. These are
application value helpers; they add no database polymorphic relation or wire codec.
