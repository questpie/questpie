QUESTPIE is a TypeScript backend framework for PostgreSQL applications.
You define stored data, permissions, and business operations. Its compiler
builds the server contract, typed client, and HTTP endpoints from those definitions.

## Why use it?

A support ticket appears in a staff screen, a server task, and a live update.
Each path needs the same answer to “may this person read or change this ticket?”
QUESTPIE applies your Policy through its data operations on all of those paths.
You write the rule once and keep the business logic in TypeScript.

A Mutation groups database changes in one transaction. A Live Query sends a
fresh authorized result when relevant data changes. Jobs keep accepted work
across process restarts, using PostgreSQL for durable state.

You still own your frontend, authentication provider, hosting, and database
operations. The Runtime is a long-lived server. Compilation is a required build
step, and database changes require reviewed migrations.

These pages document QUESTPIE 4.0.0-beta.2.

[Review the beta.2 release notes](/docs/v4/beta2-release) before installing.
Use the CLI to create the project, review migrations, apply demo data, and run
a real typed read/write before connecting the browser.
