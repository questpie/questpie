This is the frozen beta.1 inventory. The current tutorial describes a separate
[beta.2 release](/docs/v4/beta2-release); do not use its new APIs with beta.1.

`questpie@4.0.0-beta.1` is the released package version. It includes the public
CLI, compiler and Runtime in one package. Its standalone CLI binds requests to
an anonymous Principal; trusted server scripts can use generated direct execution.

## Know the beta.1 boundary

Beta.1 includes Collections, Services, Context and Policy, Queries, Mutations,
generated direct and Fetch/client execution, Live Query, durable Reaction,
maintenance compatibility, multi-instance PostgreSQL correctness, and the
archive portability fixture.

It does not include Studio, Action authoring, credential Auth, raw Routes,
generic Jobs or Job checkpoint orchestration, File bytes, Search, OpenAPI, MCP, optional cache or
brokers, split Runtime roles, a provider abstraction, non-B-tree indexes, or an
RLS claim.
