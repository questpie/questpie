This page is the beta.2 preview. Beta.2 is not published. The
[frozen beta.1 inventory](/docs/v4/beta1-release) remains the released package
contract.

## Package inventory

Beta.2 has two npm packages at one exact version. The React adapter is a
subpath, not a third package.

| Package or subpath                    | Contract                                                    |
| ------------------------------------- | ----------------------------------------------------------- |
| `questpie@4.0.0-beta.2`               | Compiler, generated contracts and clients, Runtime, and CLI |
| `questpie/react-query`                | Optional native TanStack Query adapter; no separate package |
| `questpie-opentelemetry@4.0.0-beta.2` | Official adapter with exact `questpie@4.0.0-beta.2` peer    |

The package graph contains no scoped compatibility package, forwarding alias,
or third publishable archive.
Applications using the Query Adapter supply compatible React and TanStack Query
dependencies. Core and generated clients have no React/TanStack runtime imports.
An incompatible client/adapter contract fails closed, with no compatibility path.

## Fixed limits

| Boundary                                    | Limit                   |
| ------------------------------------------- | ----------------------- |
| Inverse child lists per Query               | 1                       |
| Relation edges per Query                    | 4                       |
| Inverse child `first`                       | 1 through 50            |
| Root `first`                                | At most 100             |
| Materialized root and child positions       | At most 5,050           |
| Complete Operation or Live result           | 1 MiB (1,048,576 bytes) |
| Query Resource identities per Context scope | 128                     |
| Active Live Query watches per Principal     | 64                      |
| Dependency tokens per Live Query plan       | 256                     |

Policy filters child rows before order and limit. A failed Live Query
recomputation publishes no partial result and leaves the last successful
snapshot in place.

## Excluded from beta.2

Beta.2 adds no polymorphic Relation, polymorphic codec, descriptor, registry,
or Runtime traversal kernel. Heterogeneous values use the ordinary TypeScript
helpers.

Optimistic presentation stays in userland. Beta.2 adds no framework-owned
optimistic layers, automatic rollback/rebase, commit-to-observation fence,
TanStack DB, live infinite lists, or offline/persistence integration.

Beta.2 also adds no Workflow Resource, Cron, trigger system, generic browser
Job control, application-generated skill, broad explain command, or expanded
OpenTelemetry authority. Job remains the owner of checkpointed durable work.

No new Files, Search, Studio, split Runtime roles, Autopilot, or landing-page
surface is part of this package release.
