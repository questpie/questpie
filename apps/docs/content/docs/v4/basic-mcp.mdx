Set `projections.mcp` to `true` in `questpie.json`, then build. This exposes
every network Query, Mutation, and Action in a public tool catalogue.
There is no per-Operation MCP switch. Policy authorizes calls, not discovery of
the tool names or descriptions. Review that catalogue before exposing the endpoint.

Merge this member into the existing root configuration:

```json title="questpie.json (merge)"
{
	"projections": { "mcp": true }
}
```

The tutorial produces `query.tickets.detailPage` and `mutation.tickets.rename`.
Tool arguments derive from the existing Operation and Context codecs.
Use shared `describe` metadata; do not author another MCP schema or handler.

## Protocol and arguments

The endpoint is `POST /_questpie/mcp` using MCP `2026-07-28`.
It supports `server/discover`, `tools/list`, and `tools/call` without a session or
initialize flow. Discovery/list return JSON. Calls return request-scoped SSE
with a final `resultType: "complete"` event.

| Header                 | Required value                                         |
| ---------------------- | ------------------------------------------------------ |
| `MCP-Protocol-Version` | `2026-07-28`                                           |
| `Mcp-Method`           | Same method as the JSON-RPC body.                      |
| `Mcp-Name`             | Tool name for `tools/call`, matching the body.         |
| `Accept`               | Admit both `application/json` and `text/event-stream`. |
| `Content-Type`         | `application/json`                                     |

JSON-RPC `params._meta` contains matching
`io.modelcontextprotocol/protocolVersion` and client capabilities.
An included `Origin` must exactly match the request URL origin.
Use a client supporting this precise protocol; compatibility with other MCP
versions is not implied.

Every tool takes `input` and `context`. Query takes optional `callId`.
Mutation requires `callId`. Action requires `effectKey` and permits `callId`.
Credentials, Principal, Authority, cancellation, and deadlines are not domain
arguments. The Runtime resolves credentials and applies current Policy.

## Results and recovery

Success and Operation-error results carry matching `structuredContent` and
canonical JSON text. Error results also set `isError: true`. Malformed RPC
requests and unknown tools use JSON-RPC errors. Business errors and uncertain
write outcomes remain tool results.

MCP adds no retries. Recover a Mutation using the same Call Identity and input;
reconcile uncertain Action effects with the provider. Closing the response
cancels its execution but cannot undo a committed write.

Run `questpie explain projection mcp` to print the generated explanation from
the last build. It lists included/omitted identities and reasons without starting
the Runtime. Raw Routes, Jobs, maintenance, resources, prompts, sampling, and
application-generated skills are not exposed by this projection.
