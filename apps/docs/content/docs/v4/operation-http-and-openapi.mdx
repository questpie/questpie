Every `network: true` Query, Mutation, and Action has one compiler-derived HTTP
endpoint. Use the [generated client](/docs/v4/clients) to handle exact encoding.
For the Barbershop tutorial, the Query is `GET /_questpie/query/tickets.detailPage`
and the Mutation is `POST /_questpie/mutation/tickets.rename`.
Actions use `POST /_questpie/action/<qualifiedName>`.

## Requests

Queries have no body. Their top-level input members become sorted canonical
query parameters. Nullable null uses `~null`; bounded structured input uses
tagged canonical JSON. The encoded query limit is 16,384 bytes. Unsupported or
unbounded input fails compilation; it does not fall back to POST.

Mutation and Action JSON bodies contain exactly `input` and `context`, each
matching the application's Codec. Unknown/duplicate keys and invalid values
are rejected. Credentials remain request headers/cookies owned by Auth.

| Header                                                                     | Contract                                                     |
| -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `Questpie-Application`, `Questpie-Client-Contract`, `Questpie-Wire-Digest` | Omit all three or send the exact complete generated set.     |
| `Questpie-Context`                                                         | Query Context: unpadded base64url of canonical Context JSON. |
| `Questpie-Call-Id`                                                         | Query/Action call correlation.                               |
| `Questpie-Timeout-Milliseconds`                                            | Optional positive end-to-end deadline.                       |
| `Idempotency-Key`                                                          | Required stable Mutation identity for receipt replay.        |
| `Effect-Key`                                                               | Required Action effect identity.                             |

A partial/mismatched compatibility set returns `PROTOCOL_UNSUPPORTED` before
Operation work. Generated Query responses are private and non-cacheable across
caller scopes. Missing and invisible targets share the Operation's not-found
behavior. Neither request bodies nor generated descriptions grant authority.

## Shared Operation documentation

An Operation's optional `describe` takes a required `summary`, optional
`description`, and codec-typed `examples`. Examples require `input` and may
include `output`. They are documentation data, not executable test callbacks.

Summary is one NFC line of at most 120 Unicode scalar values. Description is
at most 1,024. Canonical examples total at most 4,096 bytes per Operation and
cannot include cursor values. Unknown members or invalid prose report
`QP-COMPOSE-030`. This metadata creates no network exposure.

## Generate application API documentation

Set `projections.openapi` to `true` in the existing `questpie.json`, then run
`questpie build`. Read `.questpie/generated/openapi.json` and
`operation-projection-explain.json`. Host the OpenAPI file with your preferred
viewer, such as Scalar; the compiler does not create that viewer.

OpenAPI 3.1 derives paths, inputs, Context, result codecs, errors, limits and
inferred tags. It shares the Operation documentation with MCP and generated
JSDoc. Prose-only changes do not change request dispatch or database schema.
Raw Routes and provider-specific security schemes are not projected.
The Runtime Codec remains authoritative where JSON Schema cannot express a rule.

## Outcomes

Exact Mutation replay recovers a receipt; changed input returns
`IDEMPOTENCY_CONFLICT`. `COMMITTED_RESULT_UNAVAILABLE` preserves committed
recovery identity. Action failure after provider dispatch may produce
`ACTION_OUTCOME_AMBIGUOUS`. No transport performs an automatic write retry.

Malformed credentials produce `UNAUTHENTICATED`; provider unavailability is a
retryable `RUNTIME_UNAVAILABLE`. Neither falls back to anonymous execution.
Public failures omit credentials, SQL, protected values, and stack traces.
