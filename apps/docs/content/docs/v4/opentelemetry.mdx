Configure OpenTelemetry when you need to inspect Barbershop requests, database
operations, and background work. The adapter observes framework-owned execution;
you do not add tracing wrappers to each Query or Mutation.

These pages document QUESTPIE 4.0.0-beta.2.

## Install and enable

```sh
bun add questpie-opentelemetry@4.0.0-beta.2
```

Install it beside `questpie`. The adapter has an exact peer version: upgrade both together.
Set your Collector endpoint and start the Runtime with
`questpie start --telemetry=opentelemetry`.

`OTEL_EXPORTER_OTLP_ENDPOINT` sets the HTTP/protobuf Collector base URL.
The default is `http://localhost:4318`. Set `OTEL_TRACES_EXPORTER=none` and
`OTEL_METRICS_EXPORTER=none` to exercise the adapter without exporting signals.
Without the CLI flag, the optional adapter is not loaded.

## Custom host lifetime

Import `createOpenTelemetry` from `questpie-opentelemetry` and pass the returned
handle as `observability` to `createApp`. Close the App first, then the adapter
in a `finally` block. Close telemetry even if App creation fails.
There is no `ctx.telemetry` capability in application handlers.

| Factory option          | Values/default                            |
| ----------------------- | ----------------------------------------- |
| `ingress.trustBoundary` | `continue` (default) or `restart`.        |
| `operationalIds`        | `omit` (default) or `spans`.              |
| `deploymentEnvironment` | Optional 1–64 printable ASCII characters. |

Unknown factory options fail. Adapter close is idempotent and bounded to
30 seconds. Export failure cannot undo application cleanup or a transaction.

## Export configuration

Supported environment variables include `OTEL_TRACES_EXPORTER`,
`OTEL_METRICS_EXPORTER`, `OTEL_EXPORTER_OTLP_ENDPOINT`,
`OTEL_EXPORTER_OTLP_HEADERS`, `OTEL_EXPORTER_OTLP_TIMEOUT`,
`OTEL_TRACES_SAMPLER`, `OTEL_TRACES_SAMPLER_ARG`, the bounded `OTEL_BSP_*`
queue/batch settings, and metric export interval/timeout.
The exporter is OTLP HTTP/protobuf or `none`; other exporter families are not enabled.

The default finished-span queue is 2,048; the default batch is 512.
A full queue drops spans instead of delaying application work. The Collector
and backend own telemetry retention. Traces are not a reliable audit ledger.

Safe framework observations omit credentials, database URLs, raw Context,
Principal/Tenant IDs, request/response payloads, SQL, provider payloads, and
exception stacks. Enabling tracing does not grant access to those values.
