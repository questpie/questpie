Choose integrations by their actual boundary. A compatible library is not the
same as a maintained QUESTPIE adapter.

| Integration                           | What is available                                               | What you own                                                                  |
| ------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| PostgreSQL                            | Required database and durable source of truth.                  | Hosting, backups, credentials, compatible locale and connection topology.     |
| Any frontend                          | Framework-neutral generated TypeScript client.                  | UI, bundling, session flow and subscription cleanup.                          |
| React + TanStack Query                | `questpie/react-query` native options and scope retirement.     | React components, QueryClient lifetime and pending presentation.              |
| TanStack Start                        | Documented native SSR/hydration integration.                    | Request-scoped cache, credential forwarding and readiness barrier.            |
| Better Auth                           | Service, credential resolver and Fetch Route composition seams. | Provider setup, tables, migrations, login UI and identity mapping.            |
| Other Fetch servers, including Elysia | Standard Fetch embedding seam.                                  | Lifecycle/worker integration; no Elysia-specific QUESTPIE adapter is shipped. |
| OpenAPI/Scalar                        | Generated OpenAPI 3.1 for network Operations.                   | Hosting a documentation UI such as Scalar.                                    |
| MCP clients                           | Optional generated stateless Tools endpoint.                    | A client supporting the exact required protocol and credentials.              |
| OpenTelemetry                         | Official exact-peer `questpie-opentelemetry` package.           | Collector/backend, retention and export configuration.                        |
| Object storage                        | Ordinary application Services/Actions/Routes.                   | The complete upload, access, verification and cleanup integration.            |
| Agent authoring                       | Portable QUESTPIE authoring skill.                              | Installation into your agent and review of its work.                          |

React and TanStack are optional peers; framework-neutral apps need neither.
There are two public npm packages: `questpie` and `questpie-opentelemetry`.
Compiler, Runtime, and testkit workspaces remain private.

There is no generated admin UI or Studio in beta.2. Search, built-in Files,
framework-managed optimism, live infinite lists, offline persistence, and
TanStack DB integration are unavailable. External tools can help implement
application behavior but do not silently add framework guarantees.

Use [React Query](/docs/v4/react-query-basic),
[TanStack Start](/docs/v4/react-query-start), [Auth](/docs/v4/auth),
[uploads](/docs/v4/uploads), [OpenAPI](/docs/v4/operation-http-and-openapi),
[MCP](/docs/v4/basic-mcp), and [OpenTelemetry](/docs/v4/opentelemetry)
for the next step. See [Package configuration](/docs/v4/definition-composition)
before distributing reusable Definitions.
