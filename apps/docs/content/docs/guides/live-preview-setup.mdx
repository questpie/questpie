---
title: Set Up Live Preview
description: Enable real-time content preview in the admin panel.
---

Live Preview keeps the normal collection form open and renders your frontend in a side-by-side iframe. The form is the source of truth — the iframe mirrors field changes in real time without saving, and all existing save/autosave/Cmd+S behavior continues unchanged.

## 1. Configure the Collection

Add `.preview()` to any collection. The `url` callback runs server-side and returns the iframe URL for the current record:

```ts title="src/questpie/server/collections/pages.ts"
import { collection } from "#questpie/factories";

export const pages = collection("pages")
  .fields(({ f }) => ({
    title: f.text(255).required().localized(),
    slug: f.text(255).required(),
    content: f.blocks().localized(),
  }))
  .preview({
    enabled: true,
    position: "right",
    defaultWidth: 50,
    url: ({ record }) => {
      const slug = record.slug as string;
      return slug === "home" ? "/?preview=true" : `/${slug}?preview=true`;
    },
  })
  .form(({ v, f }) =>
    v.collectionForm({
      fields: [f.title, f.slug, f.content],
    }),
  );
```

## 2. Wire the Frontend Page

Install the preview hooks in your page renderer. `useCollectionPreview` detects when the page is inside the admin iframe and manages the draft mirror:

```tsx title="src/components/pages/page-renderer.tsx"
import {
  BlockRenderer,
  PreviewField,
  PreviewProvider,
  useCollectionPreview,
} from "@questpie/admin/client";
import { useRouter } from "@tanstack/react-router";
import { admin } from "@/questpie/admin/admin";

export function PageRenderer({ page }) {
  const router = useRouter();
  const preview = useCollectionPreview({
    initialData: page,
    onRefresh: () => router.invalidate(),
  });

  return (
    <PreviewProvider preview={preview}>
      <article>
        <PreviewField field="title" editable="text" as="h1">
          {preview.data.title}
        </PreviewField>

        <BlockRenderer
          content={preview.data.content}
          renderers={admin.blocks}
          data={preview.data.content?._data}
          selectedBlockId={preview.selectedBlockId}
          onBlockClick={
            preview.isPreviewMode ? preview.handleBlockClick : undefined
          }
        />
      </article>
    </PreviewProvider>
  );
}
```

`PreviewField` renders as a plain element outside preview mode — no overhead for public visitors. Double-clicking an annotated field in the iframe opens an inline editor for `text` and `textarea` fields.

## 3. Annotate Block Fields

Inside each block renderer, wrap scalar values with `PreviewField`. `BlockRenderer` supplies the block scope so field names resolve automatically to `content._values.<blockId>.<field>`:

```tsx title="src/questpie/admin/blocks/hero.tsx"
import { PreviewField } from "@questpie/admin/client";
import type { BlockProps } from "../.generated/client";

export function HeroRenderer({ values }: BlockProps<"hero">) {
  return (
    <section>
      <PreviewField field="eyebrow" editable="text" as="p">
        {values.eyebrow}
      </PreviewField>
      <PreviewField field="title" editable="text" as="h1">
        {values.title}
      </PreviewField>
    </section>
  );
}
```

<Callout type="info">
Inline preview edits only apply to scalar block fields. Block tree operations (add, remove, reorder) still happen in the block editor on the form side.
</Callout>
