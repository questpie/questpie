QUESTPIE is a **server-first TypeScript framework**. You define your schema once with file-convention factories, run codegen, and get a typed runtime, an admin UI, a REST API, OpenAPI docs, a typed client, and TanStack Query — all projected from that one schema.

New here? Start with **[Getting Started](/docs/getting-started)** for the mental model and your first app. Then use **[Concepts](/docs/concepts/collections)** for server fundamentals, **[Client](/docs/client)** for frontend consumption, **[Admin](/docs/admin)** for the generated workspace, and **[Extend](/docs/extend)** for modules and plugins.
