---
title: HTTP Adapters
description: Mount QUESTPIE on TanStack Start, Hono, Elysia, or Next.js to expose your collections, routes, and auth endpoints over HTTP.
---

QUESTPIE's core is framework-agnostic. An adapter wires its internal request handler to whichever HTTP server you run. Four adapters ship out of the box.

## Which adapter should I use?

| I need... | Use... |
| --------- | ------ |
| A standalone API server with the fastest cold-start | **Hono** — zero-dep, runs on Bun, Cloudflare Workers, Deno, Node |
| End-to-end type safety with an Eden/treaty client | **Elysia** — Bun-native, full type inference from server to client |
| QUESTPIE inside an existing Next.js App Router project | **Next.js** — drop-in catch-all route handler, no extra server process |
| Full-stack app with TanStack Start (file-based routing) | **TanStack Start** — no extra package, use `createFetchHandler` directly |

## Minimal setup

<Tabs items={["TanStack Start", "Hono", "Elysia", "Next.js"]}>
  <Tab value="TanStack Start">
    No adapter package needed. `createFetchHandler` from `questpie/http` produces a standard `Request → Response` function you drop into any API file route.

    ```ts title="src/routes/api/$.ts"
    import { createAPIFileRoute } from "@tanstack/react-start/api";
    import { createFetchHandler } from "questpie/http";
    import { app } from "#questpie";

    const handler = createFetchHandler(app, { basePath: "/api" });

    export const Route = createAPIFileRoute("/api/$")({
      GET: ({ request }) => handler(request),
      POST: ({ request }) => handler(request),
      PATCH: ({ request }) => handler(request),
      DELETE: ({ request }) => handler(request),
    });
    ```
  </Tab>
  <Tab value="Hono">
    ```bash
    bun add @questpie/hono hono
    ```

    ```ts title="src/index.ts"
    import { Hono } from "hono";
    import { questpieHono } from "@questpie/hono/server";
    import { app } from "#questpie";

    const server = new Hono();

    server.route("/api", questpieHono(app));

    export default server;
    ```
  </Tab>
  <Tab value="Elysia">
    ```bash
    bun add @questpie/elysia elysia
    ```

    ```ts title="src/index.ts"
    import { Elysia } from "elysia";
    import { questpieElysia } from "@questpie/elysia/server";
    import { app } from "#questpie";

    const server = new Elysia()
      .use(questpieElysia(app, { basePath: "/api" }))
      .listen(3000);

    console.log(`Running at ${server.server?.url}`);
    ```
  </Tab>
  <Tab value="Next.js">
    ```bash
    bun add @questpie/next
    ```

    ```ts title="app/api/[...slug]/route.ts"
    import { questpieNextRouteHandlers } from "@questpie/next";
    import { app } from "#questpie";

    export const { GET, POST, PATCH, DELETE } = questpieNextRouteHandlers(app, {
      basePath: "/api",
    });
    ```
  </Tab>
</Tabs>
