Integrations are modules you add to surface what your app already knows to external consumers. Register one, run codegen, and the integration introspects your existing collections, globals, and routes — no decorators, no hand-written spec, no separate build step. Both integrations below run under your existing [access rules](/docs/concepts/access-control), so exposing an API never means bypassing your authorization.

## Available integrations

| Integration | What it does |
|---|---|
| **[MCP](/docs/integrations/mcp)** | Add `mcpModule` and your app becomes a Model Context Protocol server — collections, globals, and opted-in routes become tools an AI client can call, gated by your access rules. |
| **[OpenAPI and Scalar](/docs/integrations/openapi)** | Add `@questpie/openapi` and your whole API documents itself — an OpenAPI 3.1 spec at `/api/openapi.json` plus interactive [Scalar](https://scalar.com) docs at `/api/docs`. |
